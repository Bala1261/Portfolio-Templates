## 💻 Step-by-Step Workflow

### 1. Download & Installation

Because these templates are built using standard web technologies, **there is no installation process**. You do not need to run `npm install` or configure any build systems.

#### Option A: Clone with Git
If you have Git installed, clone this repository to your local computer:
```bash
git clone <your-repository-url>
```

#### Option B: Download as ZIP
1. Go to the GitHub repository page.
2. Click the green **Code** button at the top right.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP file to any folder on your computer.

---

### 2. How to Run Locally

You can launch and view any template using two simple methods:

#### Method A: Direct Double-Click (Zero Setup)
1. Open any template folder (e.g., `Template-4`).
2. Double-click the `index.html` file.
3. The page will instantly load in your default web browser.

#### Method B: Local Server (Recommended for Developers)
If you want to simulate a production environment or use advanced dev tools:
* **VS Code Extension**: Install the **Live Server** extension in VS Code. Open the template folder, right-click `index.html`, and select **Open with Live Server**.
* **Python**: Open terminal inside the template folder and run:
  ```bash
  python -m http.server 8000
  ```
  Then open `http://localhost:8000` in your browser.
* **Node.js (`npx`)**: Run:
  ```bash
  npx serve
  ```

---

### 3. How to Customize the Content

Every template displays structured mock data for Jane Doe. To make it yours:
1. Open the template's `index.html` file in a text editor (e.g., VS Code, Notepad++, or Sublime Text).
2. Use `Ctrl + F` (or `Cmd + F`) to search for terms like `Jane Doe` or `MIT`.
3. Replace the name, bio, projects, academic timeline, and email details with your own personal info.
4. Save the file and refresh your browser.

---

### 4. How to Share & Deploy (Publish to the Web)

There are several free, instant ways to publish your portfolio online:

#### Option A: GitHub Pages (Highly Recommended)
GitHub allows you to host static HTML pages for free:
1. Upload your code repository to GitHub.
2. Go to your repository's **Settings** tab.
3. Scroll down to the **Pages** menu on the left sidebar.
4. Under **Build and deployment**, set the Source to **Deploy from a branch**.
5. Choose your branch (usually `main`) and root folder, then click **Save**.
6. GitHub will provide a public link (e.g., `https://<your-username>.github.io/<repo-name>/Template-4/index.html`) within a minute!

#### Option B: Vercel / Netlify (Drag & Drop Deployment)
You can deploy your portfolio instantly without code:
1. Go to [Vercel](https://vercel.com) or [Netlify](https://www.netlify.com).
2. Log in and navigate to the **Deploy / Import** panel.
3. Drag and drop any single template folder (e.g. `Template-4` containing `index.html`, `style.css`, `script.js`) directly into the upload box.
4. Your website will be live at a custom URL in seconds!

#### Option C: Sharing via Email / Messaging
* Compress the template folder into a `.zip` archive (Right-click folder -> **Send to** -> **Compressed (zipped) folder**).
* Send the ZIP file to teammates, clients, or friends. They can unzip and run it on their machines instantly.
